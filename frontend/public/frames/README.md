# Carpeta de Fotogramas (Frames) para animación Scroll GSAP

Coloca aquí tus imágenes ordenadas secuencialmente para la animación de scroll.

### Formatos soportados:
- `.webp`, `.png`, `.jpg`, `.jpeg`, `.svg`

### Nomenclatura sugerida:
- `frame_001.webp`, `frame_002.webp`, `frame_003.webp`, ...
- O simplemente `1.png`, `2.png`, `3.png`, ...

### Configuración en el código:
En `src/config/frames.js` puedes definir la lista de nombres de archivos o el patrón de nombres.
Por defecto, la aplicación busca las imágenes de esta carpeta y, si no existen aún, genera fotogramas interactivos de demostración automáticamente.
